# 14. Glossary

| Term | Definition |
| --- | --- |
| AppImage | One file that holds a complete application. An installation of the file is not necessary. |
| applet | One small program in a Plasma panel. The widget of this product is an applet. |
| APT | The package manager of Debian and of Ubuntu. |
| Arch Linux | One Linux distribution. It uses pacman. |
| AUR | The Arch User Repository. It holds build scripts for packages that the official repositories do not hold. |
| bs-update | The command of this product. |
| bs-updater | This product. It has the command and the widget. |
| check | One operation that counts the available updates. |
| checkupdates | One command of the package pacman-contrib. It counts the repository updates of Arch Linux. |
| Debian | One Linux distribution. It uses APT. |
| DNF | The package manager of Fedora. |
| domain | Short form of "package domain". |
| Fedora | One Linux distribution. It uses DNF. |
| Flatpak | One application system that is independent of the distribution. |
| Gear Lever | One application that integrates AppImages into the desktop. |
| KDE Plasma | One desktop environment for Linux. This product must have version 6. |
| kpackagetool6 | The command that installs a Plasma package. |
| libnotify | The library that supplies the `notify-send` command. |
| manual check | One check that the user starts. |
| Nobara | One Linux distribution. Fedora is its base, and it uses nobara-sync. |
| nobara-sync | The update tool of Nobara. It installs RPM updates and applies the Nobara fixups. |
| Nobara fixups | The changes that Nobara applies to a system after an update. |
| package | One unit of software of a package manager. |
| package domain | One kind of package. Two tools of one domain install the same updates. |
| pacman | The package manager of Arch Linux. |
| pacman-contrib | One package of Arch Linux. It supplies `checkupdates`. |
| paru | One AUR helper for Arch Linux. It updates repository packages and AUR packages. |
| plasmoid | Another name for a Plasma applet. |
| POSIX shell | The standard command language of a Unix system. |
| QML | The declarative language of the Qt user interface. |
| repository packages | The packages of the official repositories of a distribution. |
| RPM | The package format of Fedora and of Nobara. |
| scheduled check | One check that the timer of the widget starts. |
| state file | The file `~/.cache/bs-updater/last-update`. |
| stub | One small script that replaces a real tool in a test. |
| sudo | The command that runs another command with root privileges. |
| system tray | The area of the Plasma panel that holds status icons. |
| The Unlicense | The license of this product. It puts the product in the public domain. |
| tools.conf | The configuration file with the selected tools. |
| total | The sum of the counts of each enabled source. |
| Ubuntu | One Linux distribution. Debian is its base, and it uses APT. |
| update | One newer version of a package. |
| update source | One system that supplies updates, for example Flatpak. |
| widget | The Plasma applet of this product. |
| XDG_CACHE_HOME | The variable that gives the parent of the cache directory. |
| XDG_CONFIG_HOME | The variable that gives the parent of the configuration directory. |
